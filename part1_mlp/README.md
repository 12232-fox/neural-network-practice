# Часть 1. Объектно-ориентированная реализация многослойного перцептрона

Реализация полносвязной нейронной сети с одним (или более) скрытым слоем
на чистом NumPy в рамках практического задания по дисциплине
«Основы нейронных сетей».

## Возможности

- Класс `NeuralNetwork`:
  - инициализация весов случайными числами (He-инициализация);
  - прямой проход (forward pass) с сигмоидой или ReLU;
  - обратное распространение ошибки (backpropagation) с градиентным спуском;
  - обучение по батчам с сохранением истории ошибок;
  - сохранение и загрузка весов в JSON.
- Класс `DatasetManager`:
  - загрузка данных из CSV (первая строка — заголовки, последний столбец — целевая переменная);
  - нормализация признаков (min-max или стандартизация);
  - разбиение выборки на train/test с заданной пропорцией.
- Консольное меню в `main.py` с пунктами:
  1. создать сеть;
  2. загрузить данные из CSV;
  3. обучить сеть;
  4. сделать предсказание;
  5. сохранить/загрузить веса;
  6. показать график ошибки;
  7. выход.
- Собственные классы исключений (`InvalidLayerSizeError`, `MismatchedDataError`,  `DataFileNotFoundError`, `TrainingError`).

## Настройка

Скопируйте .env.example в .env в корне проекта и при необходимости отредактируйте.
```cp .env.example .env```

| Переменная          | Назвачение                 | По умолчанию  |
|---------------------|----------------------------|---------------|
| DATA_PATH           | каталог с входными данными | ./data/input  |
| TEST_SIZE           | доля тестовой выборки      | 0.2           |
| OUTPUT_DIR          | каталог для результатов    | ./data/output |
| RANDOM_STATE        | seed для разбиения         | 42            |
| NORMALIZE_METHOD    | метод нормализации         | minmax        |



## Использование

Далее следуйте пунктам меню.

## Формат CSV

- Первая строка — заголовки столбцов.
- Последний столбец — целевая переменная.
- Остальные столбцы — числовые признаки.

Пример:
```
sepal_length,sepal_width,petal_length,petal_width,target
5.1,3.5,1.4,0.2,0
4.9,3.0,1.4,0.2,0
...
```
